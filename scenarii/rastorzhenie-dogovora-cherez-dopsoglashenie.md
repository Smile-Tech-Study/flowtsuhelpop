---
order: 9.3
title: Расторжение договора через допсоглашение
---

Если обучающийся расторг договор досрочно через допсоглашение, образовательному партнёру следует действовать по одному из сценариев ниже.



**📄 Для организаций, работающих с ручными приказами**

1. В разделе «Создать/заменить документы» подгрузите вместо заявления по СЖ доп. документ о расторжении с РР.

2. Оформите приказ на отчисление вне Флоу с указанием верной причины.

⚠️ Дублировать такой приказ на РР больше не надо.



**🤖 Для организаций, работающих с автоматическим выпуском приказов**

1. Через «Создать/заменить документы» подгрузите вместо заявления по СЖ доп. документ о расторжении с РР.

2. Оформите вне Флоу приказ на отчисление с правильной причиной.

3. Напишите обращение в техподдержку, приложите файл приказа и укажите ссылку на него.

4. Сотрудник техподдержки заменит скан приказа на корректный.

⚠️ Приказ на РР дублировать не надо.
